# MaladiesCardiaques documentation!

## Description

Les maladies cardiovasculaires sont la première cause de décès dans le monde, faisant environ 17,9 millions de morts chaque année, ce qui représente 31 % de tous les décès dans le monde. Quatre décès sur 5 par MCV sont dus à des crises cardiaques et à des accidents vasculaires cérébraux, et un tiers de ces décès surviennent prématurément chez des personnes de moins de 70 ans. L'insuffisance cardiaque est un événement courant causé par les maladies cardiovasculaires.
